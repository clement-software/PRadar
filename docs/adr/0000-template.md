# ADR-0000: Decision title

- **Status:** Proposed
- **Date:** YYYY-MM-DD
- **Owners:**
- **Related:** PRD, spec, tickets, research, or prototype pointers

## Context

Describe the forces and constraints that make a decision necessary. Include the
current evidence; avoid retelling generic architecture theory.

## Decision

State the decision precisely, including the boundary it creates or changes.

## Consequences

List the useful outcomes, costs, operational obligations, and migration impact.

## Alternatives considered

Record credible alternatives and the load-bearing reason each was rejected.

## Verification

State how code review, tests, tooling, or production signals demonstrate that
the decision remains true.
