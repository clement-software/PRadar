# Research notes

Store primary-source research as `YYYY-MM-DD-<question>.md`. Each note states
the question, scope, findings, citations, uncertainties, and recommendation.

A note is evidence, not authority. When a finding changes product scope, a
boundary, or an implementation decision, promote that conclusion to the PRD,
spec, architecture document, or ADR and link back to the note.

Do not use this directory for copied manuals, generic tutorials, raw browsing
logs, or prototype code.
